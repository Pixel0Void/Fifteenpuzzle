## 🎮 About the Project

This project recreates the classic sliding tile puzzle where the player must arrange numbered tiles in the correct order by sliding them around an empty space.

## 🛠 Features

- Developed with the **Unity** engine  
- Clean and structured **C#** code  
- Cross-platform compatibility  

## 🚀 Getting Started

### Prerequisites

- [Unity](https://unity.com/) version 2019.4.10f1 or newer installed

### Installation and Running

1. Clone the repository:
   ```bash
   git clone https://github.com/Pixel0Void/Fifteenpuzzle.git
   ```
2. Open the project in Unity  
3. Press **Play** to start the game and enjoy!
